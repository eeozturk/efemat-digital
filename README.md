# EFEMAT

A web-based mathematics learning platform that brings Prof. Dr. Murat Altun's **EFEMAT 5, 6, and 7** books into an interactive digital learning environment.

🌐 **Website:** [www.efemat.com.tr](https://www.efemat.com.tr)

## Overview

EFEMAT transforms mathematics learning materials into an interactive web experience for middle-school students and teachers. Students can work through exercises, record their answers, and track their progress, while teachers can manage classrooms, assign questions, and review student performance.

The platform is built with **Flutter and Firebase**, with secure authentication, cloud-based progress tracking, protected educational content, and integrated payments.

## Key Features

- **Interactive mathematics exercises** based on EFEMAT 5, 6, and 7
- **Student progress tracking**, including answer history and performance summaries
- **Teacher dashboard** for managing students and classrooms
- **Class and individual assignments** with selectable questions and due dates
- **Student performance review** across EFEMAT books, including recorded answers and evaluated results
- **Weekly mathematics challenges** through *Murat Hoca ile Haftanın 3 Problemi*
- **Secure user accounts and book access** with one-time purchases and lifetime access
- **Responsive web interface** for students and teachers

## Technology

- **Flutter** — web application and user interface
- **Firebase Authentication** — account and sign-in management
- **Cloud Firestore** — learning progress, classroom, and assignment data
- **Cloud Functions** — server-side workflows and access-related operations
- **Firebase Hosting** — web deployment
- **Shopier integration** — payment and purchase workflows
